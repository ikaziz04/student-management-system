# Student Management System

A simple Student Management System developed in C++ as part of my programming learning journey.

## About the Project

This console-based application allows users to manage student information and perform basic operations using C++.

## Features

- Add a new student
- Display all students
- Search for a student
- Delete a student
- Find the student with the highest average
- Calculate the class average

## Technologies Used

- C++
- Standard Template Library (STL)
- `vector` for storing student data
- `struct` for organizing student information
- Functions and loops

## What I Learned

Through this project, I practiced:

- Creating and using structures (`struct`)
- Working with vectors
- Writing and calling functions
- Using loops and conditional statements
- Managing and searching data
- Calculating averages

## How to Run

1. Download or clone this repository.
2. Open the `.cpp` file in a C++ IDE, such as Visual Studio Code or Visual Studio.
3. Compile and run the program using a C++ compiler.
